# BarotraumaMod

潜渊症 mod 仓库，目前包含两个**互相独立**的内容包：

| 目录 | 内容包 | 说明 |
|---|---|---|
| 根目录 | `BarotraumaMod` | 早期测试包（test.xml + 素材目录） |
| `LOTM_Pathways/` | 愚者途径 LOTM Pathways | 《诡秘之主》× 潜渊症，愚者途径（占卜家 → 小丑 → 魔术师） |

---

## 愚者途径 LOTM Pathways

把《诡秘之主》的序列体系缝进潜渊症：喝魔药踏上途径，用能力推进"扮演消化"，消化不足就晋升会失控。

### 安装

1. 把 `LOTM_Pathways/` 整个目录复制到 `Barotrauma/LocalMods/`
2. 确保已安装 **LuaCsForBarotrauma**（创意工坊）**并打过客户端补丁**
   - 补丁地址：https://github.com/evilfactory/LuaCsForBarotrauma/releases/tag/latest
   - 下载 `luacsforbarotrauma_patch_windows_client.zip`，解压覆盖到游戏根目录
   - 未打补丁时 Lua 完全不会执行，mod 的物品能用但所有机制失效
3. 游戏内模组列表启用，顺序：LuaCs 在上，本 mod 在下

### 已实现

- **序列状态**：序列 9 占卜家 / 8 小丑 / 7 魔术师，常驻 buff，提升生命上限、移速、近战、减伤、憋气
- **三条资源**：灵性（自然回复）、疯狂（不衰减、70% 起侵蚀理智）、扮演消化度
- **灵视**：主动开关，持续消耗灵性，枯竭自动关闭并附加"灵视反噬"
- **完整原著配方**：17 种材料，医疗台只有 5 格，所以拆成"基液 → 魔药"两步
- **双晋升路线**：原著材料路线 / 非凡特性替代路线
- **风险判定**：未消化强行晋升按 `(100-消化)×0.6` 累积疯狂，满 100 失控死亡并原地生成怪物
- **死亡掉落非凡特性**：尸体旁生成对应特性，可被队友回收
- **占卜**：关键词匹配 + 真实游戏状态（附近活物、重伤船员），准确率随消化度提升
- **HUD**（实验性）：生命/灵性/疯狂/消化四条文本进度条 + 灵视、占卜按钮

### 聊天指令

| 指令 | 说明 |
|---|---|
| `!状态` / `!status` | 查看生命、灵性、疯狂、消化、序列 |
| `!灵视` / `!vision` | 开关灵视 |
| `!占卜 问题` / `!divine 问题` | 占卜，需要随身携带占卜水晶，消耗 30 灵性 |
| `!界面` / `!hud` | 显示/隐藏 HUD |
| `!lotm` | 自检，确认脚本在线 |

> 这些是**聊天指令**（按 T 打开聊天框），不是 F3 调试控制台命令。

### 文件结构

```
LOTM_Pathways/
├─ filelist.xml          内容包声明
├─ ModConfig.xml         LuaCs 脚本声明（IsAutorun）
├─ Afflictions.xml       序列 / 灵性 / 疯狂 / 消化 / 灵视 状态
├─ Items/
│  ├─ Materials.xml      17 种原著材料
│  ├─ Potions.xml        基液 + 魔药 + 非凡特性 + 配方
│  └─ Tools.xml          占卜水晶、纸人
├─ Texts/                中英文文本
├─ Lua/lotm.lua          逻辑层（ASCII only，中文走 Texts）
└─ 使用说明.txt          详细说明与测试清单
```

### 已知限制

- HUD 为实验性 GUI 挂载，显示异常时用聊天指令
- 多人模式未做联网同步（单机优先）
- 占卜是关键词匹配，不是自由问答
- 纸人替死、火焰跳跃等主动技能尚未实装

### 依赖说明

LuaCs 的客户端补丁会替换游戏根目录的 `Barotrauma.dll` 等文件，**Steam 每次更新游戏都会覆盖回原版**，更新后需要重打补丁。
