【v0.3 修了什么】
v0.2 的脚本完全没被执行。原因已确认：
  LuaCs 1.0.117 的二进制里没有扫描 Lua/Autorun 目录的代码，
  只认 ModConfig.xml 里的显式声明。
所以这一版改成：
  1. 新增 ModConfig.xml，显式声明 Lua/lotm.lua 并 IsAutorun="true"
  2. 脚本开头打印运行环境（SERVER / CLIENT），方便排查
  3. 脚本改成纯 ASCII，所有中文提示放进 Texts，用 TextManager 读取
  4. 去掉 v0.2 里那句 if SERVER then return end（单机可能直接返回）

【启用】
主菜单 → 模组 → 启用「LuaCsForBarotrauma」和「愚者途径 LOTM Pathways」
注意顺序：LuaCs 在上，本 mod 在下。

【怎么确认脚本活了】
进游戏后按 F3 打开控制台，应该能看到：
    [LOTM] boot: SERVER=... CLIENT=...
    [LOTM] HUD created
    [LOTM] init done
聊天框输入 !lotm，应该回一条：
    [LOTM] online SERVER=... CLIENT=...

一条都没有 → 脚本还没加载，把控制台截图发我。

【聊天指令（中英都支持）】
    注意：这些是"聊天指令"，要按 T 打开游戏内聊天框输入，
          不是按 F3 的调试控制台（那里只认 spawnitem 这类命令）。

    !状态   / !status        查看生命/灵性/疯狂/消化/序列
    !灵视   / !vision        开/关灵视（需要已踏上途径，灵性 ≥ 20）
    !占卜 问题 / !divine 问题  占卜（需要随身携带占卜水晶，消耗 30 灵性）
    !界面   / !hud           显示/隐藏左下角面板
    !跳跃   / !jump          火焰跳跃（序列7）
    !幻术   / !illusion      幻术（序列7）
    !lotm                    自检，确认脚本在线

    改完 lua 文件后，在 F3 控制台输入 cl_reloadluacs 即可热重载，不用重启游戏。

占卜能识别的问题：
    怪物 / 活物 / 危险 / 敌   → 附近有没有活着的非人类
    队友 / 船员 / 同伴        → 有没有重伤的船员
    其他                      → 随机（准不准看消化度）

【玩法循环】
1. 医疗台熬基液（医疗 10/12/15）→ 基液 + 主材料合成魔药（医疗 15/20/25）
2. 喝下第一瓶 → 踏上序列 9
3. !灵视 → 灵性持续流失，枯竭自动关闭 + 灵视反噬
4. !占卜 → 灵性 -30，消化 +8
5. 消化高了再喝下一瓶 → 风险低；没消化硬喝 → 疯狂飙升
6. 疯狂满 100 → 失控死亡，尸体旁掉出非凡特性

【关于改名】
    内容包名称从「愚者途径 LOTM Pathways」改成了「LOTM_Pathways」。
    原因是 LuaCs 的按键设置文本键要用 "<包名>.<设置名>.DisplayName" 的格式，
    包名里有中文和空格会导致设置项标题无法翻译。功能不受影响。
【主动技能（v0.4）】
    快捷键（可在 LuaCs 模组设置里改）：F 火焰跳跃，G 幻术，V 灵视
    也可以用聊天指令 !跳跃 / !幻术 / !灵视

    纸人替身（序列8及以上，被动）
        受到致命伤时自动消耗一个纸人，抵消这次死亡（包括失血、撕裂伤这类持续伤害致死），
        但会留下重伤（出血 + 内伤）并增加 25 点疯狂。冷却 90 秒。

    伤害转移（序列7，被动）
        单次受到超过 20% 最大生命的伤害时，消耗一个纸人，
        把 40% 的伤害转走。冷却 15 秒。

    火焰跳跃（序列7，主动）
        朝鼠标方向瞬移约 6 米，消耗 35 灵性，冷却 20 秒。
        不穿墙；落点如果在结构里可能卡住，先别往墙里跳。

    幻术（序列7，主动）
        8 秒内怪物忽略你，消耗 25 灵性，冷却 45 秒。

    以上技能使用时都会推进消化度（纸人 10、转移 6、跳跃 12、幻术 8）。
【已知限制】
- HUD 属实验性挂载，显示异常就用聊天指令
- 多人模式未做联网同步（单机优先）
- 占卜是关键词匹配 + 真实游戏状态，不是自由问答
- 火焰跳跃不检测墙体，往墙里跳可能卡住；幻术对部分特殊 AI 可能无效
